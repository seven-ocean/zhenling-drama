## TEST.md BUG 修复（BUG00009~00010）

### BUG00009: /drama/new 页面空白
**根因**: DramaDetail.vue 是路由复用组件（`/drama/xxx` ↔ `/drama/new` 切换不重新 mounted），onMounted 只执行一次，路由切换后 isNew 变了但初始化不触发 → store.currentDrama 为 null → `v-if="isNew && store.currentDrama"` 条件不满足。
**修复**:
1. 新增 `initPage()` 函数统一处理新建/编辑模式初始化
2. 添加 `watch(route.params.id)` 监听路由变化并重调 initPage()
3. 新建模式下先 `store.reset()` 清理旧数据再设默认值

### BUG00010: 全页面按钮 icon+文字纵向对齐
**根因**: 导航栏用原生 button+显式 flex 对齐OK；其余 a-button 在暗色主题下 icon 与文字未垂直居中。
**修复**: App.vue 底部新增全局非 scoped `<style>` 块：
- `.ant-btn { display:inline-flex !important; align-items:center !important; gap:6px }`
- `.ant-btn .anticon { display:inline-flex !important; align-items:center }`
全局生效覆盖所有页面的 Ant Design 按钮。

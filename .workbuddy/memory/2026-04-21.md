## BUG 修复执行（第二批，BUG00030）

### BUG00030: AI 接口错误信息透传

**问题**: MiniMax API 返回具体错误码(如1008=余额不足)时，MiniMaxAdapter 只打日志后静默返回空字符串 `""`。用户只看到笼统的"AI返回为空"或"TTS返回为空"，完全不知道真实原因。

**修复内容**:
1. **新增 `AiApiException.java`** — 自定义异常类，包含 vendorCode/vendorMessage/userMessage/operation 四层信息
2. **MiniMaxAdapter 全面重构5个方法**: generateText/generateImage/generateVideo/generateVideoMultiMode/generateTTS
   - 新增 `ensureSuccess()` 替代旧的 `isSuccess()` 静默检查
   - 新增 `translateErrorCode()` 翻译常见错误码(1008→余额不足, 1001→API Key无效, 1013→频率限制, 1014→安全审核)
3. **上层 Service 适配4个文件**: VideoService/ImageGenerationService/TtsService/StoryboardService 全部增加 AiApiException catch 分支
4. **VideoService 新增 saveFailedVideo()** 保存失败记录供前端展示
5. **修改文件**: `AiApiException.java`(新), `MiniMaxAdapter.java`(大改), `VideoService.java`, `ImageGenerationService.java`, `TtsService.java`, `StoryboardService.java`, `TEST.md`

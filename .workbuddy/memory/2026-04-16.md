## BUG00016 修复 — RestTemplate 不走系统代理导致 UnknownHostException

**问题**：后端调用 MiniMax API 时报 `java.net.UnknownHostException: api.minimaxi.com`。

**根因演变**：
- 第一轮：UnknownHostException → 域名无法解析
- 修复：配置 HTTP 代理 → 进步到 404 代理响应
- 第二轮：Unable to tunnel through proxy → :8888 是宝塔面板（btPanel），不是 HTTP CONNECT 代理
- 最终确认：机器上无标准代理软件（7890/1080/10808 均不存在），浏览器走插件/TUN 模式，JVM 不可见

**最终修复（4处改动）**：
1. `pom.xml` — 新增 `okhttp:4.12.0` 依赖
2. `RestTemplateConfig.java` — 完全重写，底层换用 `OkHttp3ClientHttpRequestFactory`，自定义 `Dns` 实现用 Google DNS（8.8.8.8）解析
3. `application-dev.yml` — `proxy.enabled=false` 直连，`dns.enabled=true`，`dns.servers=8.8.8.8,8.8.4.4`
4. `spring-boot-maven-plugin` — 添加 JVM 网络参数（`-Dnetworkaddress.cache.ttl=-1` 等）

**MiniMax API 端点确认**：`https://api.minimaxi.com/v1/image_generation`，模型 `image-01`。

## BUG00017 修复 — 服务层硬编码 OpenAI 模型名

**问题**：图片生成报错 `unsupported model: dall-e-3`；文本生成报错 `unknown model 'gpt-4o'`。

**根因**：服务层直接传入了 OpenAI 模型名，而非让适配器使用 DB 配置中的 MiniMax 模型。

**修复（2处）**：
1. `StoryboardService.generateFromScript()`：`"gpt-4o"` → `null`，适配器使用 DB 中的 `MiniMax-M2.5`
2. `ImageGenerationService` 三个方法（character/scene/grid）：`"dall-e-3"` → `null`，适配器使用 DB 中的 `image-01`

**MiniMax 支持的模型（官方文档）**：
- 文本：`MiniMax-M2.5` / `MiniMax-M2.5-highspeed` / `MiniMax-M2.1` 等
- 图片：`image-01` / `image-01-live`

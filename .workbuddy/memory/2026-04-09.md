### BUG00003/04: 前端 API 请求 404（ofetch 实例未生效）
**根因**: `request.ts` 中 `ofetch.create({ baseURL: '/api/v1' })` 创建了带前缀实例，但 `export default ofetch` 导出的仍是原始 ofetch（无 baseURL）。导致所有请求直接打 `/dramas` 而非 `/api/v1/dramas`，Vite proxy 只转发 `/api` 开头路径 → 404。
**修复**: 
- 将 create 实例赋值给 `const api` 并 `export default api`
- 所有 API 函数（dramaApi/characterApi/sceneApi/storyboardApi/audioApi/videoApi）改用 `api()` 调用
- 顺手修了 `videoApi.generate` 的笔误（`offetch` → `api`）
- TEST.md 已同步更新为"已修复"
